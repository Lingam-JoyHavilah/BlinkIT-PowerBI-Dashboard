# BlinkIT Grocery Sales Analysis Dashboard

## Project Overview

This is my first Power BI mini project based on BlinkIT grocery sales data.

The dashboard provides an interactive view of grocery sales performance and helps analyze different product and outlet-related factors.

## Key Performance Indicators

- Total Sales
- Average Sales
- Average Rating
- Total Items

## Dashboard Analysis

The dashboard allows users to analyze sales based on:

- Item Fat Content
- Item Type
- Outlet Tier
- Outlet Size
- Outlet Type
- Other available product and outlet attributes

The dashboard includes interactive filters that allow users to select different categories and view the corresponding changes in the dashboard.

## Tools Used

- Microsoft Power BI
- Power Query
- Data Visualization

## Key Features

- Interactive dashboard
- KPI cards
- Sales analysis
- Product-level analysis
- Outlet-level analysis
- Interactive filters and slicers
- Visual comparison across different outlet tiers
